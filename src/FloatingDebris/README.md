# Floating Debris

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://github.com/zimasu/broken-printer/blob/main/LICENSE)
[![Ko-fi](https://img.shields.io/badge/Ko--fi-zimasu-FF5E5B?logo=ko-fi&logoColor=white)](https://ko-fi.com/zimasu)

A revival of [Heinermann's Floatation](https://github.com/heinermann/ONI_Mods/tree/master/Floating).

## What it changes

- Extended to make all debris float, unlike the original which only floated some objects.

## Building from Source

You'll need **Visual Studio 2022** and **dnSpy** to decompile game .dll files for reference.
See [Cairath's modding wiki](https://github.com/Cairath/Oxygen-Not-Included-Modding/wiki) for a full setup guide.
