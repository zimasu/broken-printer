\# ExpressiveDupes



\[!\[License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://github.com/zimasu/broken-printer/blob/main/LICENSE)

\[!\[Ko-fi](https://img.shields.io/badge/Ko--fi-zimasu-FF5E5B?logo=ko-fi\&logoColor=white)](https://ko-fi.com/zimasu)



Dupes were always more expressive than the base game let on — this mod just lets them show it.



\## What it changes



\- Dupes \*\*smile by default\*\*. The flat (.\_.) face is now reserved for stoic dupes only.

\- Dupes use their \*\*selection screen idle animation\*\* while hanging around the colony.

\- Past certain thresholds — stress, sadness, injury — \*\*vanilla expressions take over\*\* as normal.



No new assets. Everything here already lives inside the game.
