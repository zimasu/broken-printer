# Imperfect Copy

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](../../LICENSE)
[![Ko-fi](https://img.shields.io/badge/Ko--fi-zimasu-FF5E5B?logo=ko-fi&logoColor=white)](https://ko-fi.com/zimasu)

Based on [Zonkeeh's DuplicantLifecycles](https://github.com/Zonkeeh/ONI-Mods).

## What it changes

- Duplicants have a randomized lifespan of 14 to 28 cycles, unique and deterministic per duplicant
- Life stages scaled proportionally to their personal lifespan: Fresh Copy (0-45%), Unstable DNA (45-75%), Degrading Copy (75-90%), Terminal (last 10%)
- Bionic duplicants are immune to aging
- Guaranteed death once their personal max age is reached

## Building from Source

You'll need **Visual Studio 2022** and **dnSpy** to decompile game .dll files for reference.
See [Cairath's modding wiki](https://github.com/Cairath/Oxygen-Not-Included-Modding/wiki) for a full setup guide.
